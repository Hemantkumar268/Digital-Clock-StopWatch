# Digital Clock & Stopwatch

A responsive web project built using HTML, CSS, Bootstrap, and JavaScript.

## Features
- Digital clock with 12-hour and 24-hour formats
- Live date and time display
- Stopwatch with Start, Stop, Reset, and Lap functionality
- Responsive design

## Technologies Used
- HTML5
- CSS3
- Bootstrap 5
- JavaScript

## How to Run
Open `index.html` in your browser.
